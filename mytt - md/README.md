
# My Time Table (mytt)

### 나에게 딱 맞는 시간표를, AI로 직접 만드는 한 달

시간관리 앱은 많은데, 왜 나한테 맞는 건 하나도 없을까요?

남이 만든 툴에 내 하루를 억지로 끼워 맞추는 대신, **AI에게 시켜서 나만의 시간표 웹페이지를 직접 만드는** 클래스입니다. 코딩을 배우는 수업이 아니라, **내 시간을 다시 설계하고 한 달 동안 실제로 굴려보는** 프로그램이에요.

---

## 이런 분들을 위해 만들었어요

- 혼자 일하는 **1인 창작자 · 프리랜서** — 출퇴근도 마감도 내가 정해야 하는 사람
- **대학원생** — 스스로 관리하지 않으면 하루가 통째로 사라지는 사람
- 그림책 강사, 작가, 디자이너처럼 **내 시간을 갈아서 결과물을 만들어내는** 직군
- "AI, AI 하는데 나만 모르는 것 같은데…" 싶어서 계속 미뤄뒀던 분

> 개발 경험, 전혀 필요 없습니다. HTML이 뭔지 몰라도 괜찮아요.


---

## 무엇을 만드나요

**나만의 시간표 + 시간표 관리 툴** (웹페이지 형태)

만들면서 이런 걸 갖게 됩니다.

| | |
|---|---|
| **고정 루틴 블록** | 어떤 시간에 무엇을 할지 눈에 보이는 형태로 고정 |
| **항상 보이는 시각화** | 머릿속에만 있던 계획을 계속 눈앞에 띄워두기 |
| **함께하는 환경** | 오픈채팅방에서 서로 인증하며 혼자 무너지지 않게 |

세 가지 모두 "의지가 약해서 못 하는 게 아니라, 환경이 안 받쳐줘서 못 한다"는 전제 위에서 설계했습니다.

---

## 어떻게 진행하나요

**한 달 · 4회차 온라인 모임 + 오픈채팅방 챌린지**

**1회차 — 내 시간 고해성사**
AI에게 내 하루를 낱낱이 털어놓고, 시간이 어디서 새는지 같이 분석합니다. 여기서 내 타임테이블의 뼈대를 잡아요.

**2회차 — AI로 시간표 만들기**
프롬프트를 넣어 실제로 동작하는 시간표 페이지를 만들어봅니다. 준비된 프롬프트 세트를 그대로 따라오시면 됩니다.

**3회차 — 내 취향대로 고치기**
원하는 기능을 추가하고, 색과 디자인을 내 것으로 바꿉니다. 이때부터 확실히 '내 물건'이 돼요.

**4회차 — 일주일 써보고 회고**
실제로 일주일 사용한 뒤, 안 맞는 부분을 뜯어고칩니다. 그리고 다 같이 회고.

기간 중에는 오픈채팅방에서 숙제 인증과 응원이 이어집니다.

---

## 수강 옵션

**베이직**
4회차 온라인 모임 · 오픈채팅방 숙제 인증 · 1달 챌린지 전 과정

**프로**
베이직 전 과정 + 1:1 코칭 · 디자인 업그레이드 툴킷 (소수 정원)

---

## 준비물

- 노트북 (인터넷 연결)
- AI 계정 (클로드, 제미나이, GPT ...)
- 그리고 "이번엔 진짜 내 시간을 잡아보겠다"는 마음 한 스푼

---

## 이 클래스가 약속하는 것

코딩 실력이 아니라, **한 달 뒤에도 계속 쓰게 되는 내 시간표 하나**와 **AI를 도구로 부려본 첫 경험**을 가져가시게 됩니다.
