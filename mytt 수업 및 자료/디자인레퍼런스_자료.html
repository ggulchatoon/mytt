실무 디자인 원칙 3가지
  • 섀도짙은 검정 그림자는 2000년대 느낌을 줍니다. 옅고 넓은 소프트 섀도(rgba 0.04~0.06)를 쓰세요.
  • 라운드부모 컨테이너가 18px이면 자식 카드는 12px, 버튼은 8px로 안쪽으로 갈수록 작아져야 자연스럽습니다.
  • 여백요즘 앱이 세련되어 보이는 비밀의 80%는 폰트가 아니라 카드 안쪽 16~20px의 넉넉한 padding입니다.

바이브코딩 AI 요청문

웹앱의 디자인 스타일을 설정해 줘: - 전체 테마: 토스·애플 스타일 (Clean Soft Modern) - 메인 색상: 배경 #f8fafc, 카드 #ffffff, 포인트 #3182f6, 텍스트 #0f172a - 모서리 곡률: 부모 카드 18px, 버튼 10px, 뱃지 999px 알약 - 박스 스타일: 보더 없이 은은하고 넓게 퍼지는 소프트 섀도 (0 6px 20px -2px rgba(0,0,0,0.06)) - 폰트: 기본 UI 폰트로 'Pretendard' 웹폰트를 적용해서 정갈하게 잡아줘.
02

4대 토큰 실무 가이드

선택 기준

감각이 아니라 공식으로 고릅니다. 색감, 라운드, 박스, 폰트 4가지만 잡으면 어떤 툴이든 상용 앱 수준의 완성도가 나옵니다.

토큰 조합 치트시트

① 색상 60-30-10 법칙

배경(60%)은 흰색/미색, 카드 및 텍스트(30%)는 무채색, 브랜드 강조색(10%)은 버튼 하나에만 씁니다.

② 라운드 일관성

한 화면에서 4px(각진)와 24px(동글)을 섞지 마세요. 스케일 하나를 정해 전체 화면에 통일합니다.

③ 박스는 '보더' 또는 '섀도' 중 택 1

테두리 선과 그림자를 동시에 진하게 넣으면 화면이 무거워집니다. 둘 중 하나만 은은하게 남기세요.

④ 폰트는 최대 2종

기본 본문은 무조건 읽기 편한 Pretendard나 Inter를 두고, 제목/숫자에만 개성 폰트 1개를 섞습니다.

4가지 토큰이 정렬되면 AI가 코드를 짤 때도 스타일 혼선이 없습니다.

디바이스별 추천 폼팩터

모바일 웹앱: 손가락 터치 반경을 고려해 16~20px의 넉넉한 소프트 라운드와 44px 이상 터치 영역이 잘 어울립니다.

데스크톱 dmg 위젯: 화면 구석에 상시 띄워두는 툴이므로, 1px 미세 보더와 8~10px의 정돈된 모던 라운드가 최적입니다.

요청문

모바일 화면은 전체 카드 여백 16px, 버튼 높이 48px, 라운드 16px로 잡고, 맥용 데스크톱 위젯으로 볼 때는 상단 윈도우 바를 포함한 컴팩트 창으로 패딩을 12px로 줄여줘.
03

컨셉별 추천 매칭표

1초 선택 가이드

내가 기획한 시간관리 툴의 목적에 따라 가장 검증된 룩앤필 매칭표입니다.

내가 만든 기능 컨셉 추천 비주얼 룩앤필 색감 & 박스 추천 폰트
깔끔한 투두리스트 / 포모도로 토스·애플 스타일 화이트 + 토스 블루 / 에어 섀도 Pretendard
개발자용 집중 터미널 / 스톱워치 리니어 다크 테크 옵시디언 딥블랙 + 에메랄드 / 1px 보더 D2Coding / Inter
단정한 타임블록 / 주간 일정표 노션 미니멀리즘 웜 그레이 + 모노크롬 / 플랫 톤온톤 Pretendard (샤프 4px)
심야 회고록 / 감정 저널 킨포크 페이퍼 미색 웜크림 + 올리브 / 얇은 디바이더 마루부리 / Gowun Batang
루틴 스티커판 / 칭찬 도장 귀여운 캐릭터 젤리 베리 핑크 + 버터 크림 / 폭신한 라운드 주아 (Jua) / 개구
마감 카운트다운 / 긴급 타이머 뉴-브루탈리즘 비비드 옐로우 + 블랙 / 2px 하드 외곽선 검은고딕 / G마켓 산스

자주 하는 실수 4가지

디자인 커스텀을 시작할 때 초보자가 가장 자주 빠지는 함정입니다.

01

섀도가 짙으면 2000년대 웹이 됩니다

포토샵 기본 검정 그림자(opacity 0.3 이상)는 화면을 둔탁하게 만듭니다. 그림자는 보일 듯 말 듯한 0.04~0.06 투명도로 넓게 퍼뜨려야 세련됩니다.

02

라운드가 제각각이면 조잡해 보입니다

버튼은 20px인데 인풋은 0px 각진 네모면 서로 다른 앱을 이어 붙인 것처럼 보입니다. 패밀리 라운드 규칙을 세우세요.

03

색상은 3가지 이하로 절제하세요

포인트 컬러가 4개를 넘어가면 어디가 중요한 버튼인지 눈이 길을 잃습니다. 한 화면에 눈에 띄는 유채색은 딱 1개면 충분합니다.

04

폰트 욕심은 2개까지만 부리세요

제목, 본문, 버튼, 타이머 숫자에 서로 다른 폰트를 쓰면 피로도가 급상승합니다. 기본 고딕 1개에 포인트 폰트 1개로 제한하세요.

헷갈리는 짝

디자인 선택이 망설여질 때 기준을 세워주는 비교입니다.

미세 1px 보더 vs 에어 소프트 섀도모바일에서는 소프트 섀도가 터치감을 살리고, 데스크톱 밀집 대시보드에서는 1px 보더가 시원합니다.
올블랙(#000000) vs 딥 옵시디언(#0f172a)진짜 순수 검정은 눈의 피로를 유발합니다. 고급 다크모드는 언제나 짙은 남색이나 차콜 그레이를 씁니다.
모던 산스 vs 기하학 고딕본문이 많으면 Pretendard 같은 모던 산스가 안전하고, 큰 숫자나 헤드라인엔 G마켓 산스 같은 기하학 고딕이 강렬합니다.
소프트 라운드 vs 알약 캡슐카드는 12~18px 소프트 라운드로 품고, 작고 누를 수 있는 뱃지나 태그만 999px 알약으로 씁니다.
