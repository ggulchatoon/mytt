# mytt 클래스 웹 자료집 디자인 시스템 (Design System)

> **기준 파일**: `/Users/hnky/agyspace/mytt 수업 및 자료/구성요소.html`  
> **용도**: 앞으로 제작되는 모든 mytt 클래스 공식 웹 수업자료 및 교안(HTML)은 본 문서에 정의된 디자인 시스템 규격을 100% 준수하여 제작합니다.

---

## 1. 디자인 철학 및 기본 원칙

1. **내용 중심의 단정한 미니멀리즘 (Content-First & Sharp Clean)**
   - 화려한 그래픽이나 불필요한 장식을 배제하고, 텍스트와 UI 부품 자체의 완성도로 신뢰감을 줍니다.
   - 배경은 깨끗한 순백색(`#FFFFFF`)과 밝은 회색(`#F8F9FA`)을 기본으로 합니다.
2. **샤프하고 정제된 곡률 (Consistent 4px Radius)**
   - 둥글둥글한 캐주얼 느낌 대신, **`4px`의 일관된 마이크로 라운드**를 사용하여 도구(Tool)이자 워크시트다운 전문성을 유지합니다.
3. **바이브코딩 최적화 브랜드 그린 (`#00C471`)**
   - 인프런/테크 느낌의 산뜻하고 명료한 그린을 주 액센트로 사용하여 활력과 집중도를 부여합니다.
4. **인터랙티브 벤치 구조 (직접 조작 + 실무 기준 + AI 프롬프트)**
   - 모든 컴포넌트/개념은 **좌측 조작 스테이지(실시간 인터랙션)**와 **우측 학습 노트(실무 기준 + 복사용 프롬프트)**의 2단 구조를 갖춥니다.

## 2. 디자인 토큰 (CSS Variables)

  --surface2: #F8F9FA;      /* 보조 배경 (헤더, 아웃풋 바, 빈 상태 박스) */

  /* 2. 텍스트 / 잉크 */

  /* 3. 보더 / 구분선 */
  --line: #E9ECEF;          /* 은은한 섹션 구분선 */
  --line-strong: #DEE2E6;   /* 컨테이너 및 인풋 외곽선 */

  /* 4. 브랜드 컬러 (mytt 그린) */
  --brand: #00C471;         /* 주 강조색, 진행바, 액티브 탭 */
  --brand-dark: #00A45E;    /* 버튼 호버, 뱃지 텍스트 */
  --brand-soft: #E7F9F1;    /* 뱃지 배경, 틴트 하이라이트 */

  /* 5. 카테고리 컬러 (기본은 브랜드 그린에 맞춤) */
  --amber: #00C471;

```
+-------------------------------------------------------------------+
|  .wrap (max-width: 1120px; padding: 0 24px;)                      |
|                                                                   |
|  [Header .masthead]                                               |
|  - .eyebrow (강의 차시 뱃지)                                         |
|  - h1 (제목)                                                       |
|  - .goals (학습 목표 3열 그리드 - 상단 2px 그린 보더)                 |
|                                                                   |
|  +-------------------------------------------------------------+  |
|  |  .cols (grid 172px 1fr; gap: 56px;)                         |  |
|  |                                                             |  |
|  |  [좌측 네비게이션 .rail]      [우측 본문 <main>]               |  |
|  |  - sticky 사이드바           - .part (섹션 01)                |  |
|  |  - 01 버튼                  - .part (섹션 02)                |  |
|  |  - 02 체크박스              - ...                            |  |
|  |  - 03 입력창                - [실험실 / 퀴즈 / 워닝 블록]      |  |
|  |  - ...                      - [Footer]                       |  |
|  +-------------------------------------------------------------+  |
+-------------------------------------------------------------------+
```

### 1) 상단 마스트헤드 (`.masthead`)
- `.eyebrow`: 배경 `--brand-soft`, 글자색 `--brand-dark`, 패딩 `4px 10px`, 라운드 `4px`.
- `.goals`: 3개 학습 목표를 가로 3열로 배치.
  - 각 항목 상단에 `border-top: 2px solid var(--brand)`
  - 순번 표기: CSS Counter로 `01`, `02`, `03`을 `IBM Plex Mono`로 자동 출력.

### 2) 2단 컬럼 구조 (`.cols`)
- 데스크톱 (`min-width: 980px`): `grid-template-columns: 172px 1fr; gap: 56px; align-items: start;`
- 모바일: 1열 그리드로 전환되며, `.rail`은 화면 상단에 수평 스크롤 바로 sticky 고정.

### 3) 목차 레일 (`.rail`)
- `position: sticky; top: 32px;`
- 항목마다 1px 구분선(`--line`), 호버 시 그린(`--brand`) 하이라이트.

## 5. 섹션 표준 구조 (`.part` & `.bench`)

모든 학습 주제/컴포넌트 섹션은 아래 규격으로 통일합니다.

```html
<section class="part" id="p01">
  <!-- 1. 헤더 영역 -->
  <div class="part-head">
    <span class="num">01</span>
    <h2>버튼</h2>
    <span class="cat">누르는 것</span>
  </div>
  <p class="lede">누르면 어떤 일이 실행되는 부품.</p>

  <!-- 2. 작업대 영역 (2단 그리드: 1.25fr vs 0.95fr) -->
  <div class="bench">
    <!-- 좌측: 직접 조작해 보는 인터랙티브 스테이지 -->
    <div class="stage">
      <div class="row">
        <!-- 실제 조작 컴포넌트 -->
      </div>
      <p class="readout" id="r-btn">아직 누르지 않았습니다.</p>
    </div>

    <!-- 우측: 설명 + 기준 + AI 복사용 요청문 -->
    <div class="notes">
      <div class="note">
        <p class="note-l">언제 쓰나</p>
        <p>저장·삭제 같은 <strong>확정 동작</strong>. 채워진 버튼은 한 화면에 하나만.</p>
      </div>

      <details class="more">
        <summary>실무 기준 3가지</summary>
        <ul class="spec">
          <li><b>크기</b>터치 영역 최소 44×44px</li>
          <li><b>상태</b>기본·올림·눌림·비활성·로딩 5종</li>
          <li><b>글자</b>동사로. "저장" → 안내도 "저장됨"</li>
        </ul>
      </details>

      <div class="note">
        <p class="note-l">요청문</p>
        <div class="prompt">
          채워진 "기록 저장" 버튼과 테두리만 있는 "취소" 버튼. 저장을 누르면 "저장 중…"으로 바뀌고 다시 못 누르게. 높이 44px 이상.
        </div>
        <button class="copy">요청문 복사</button>
      </div>
    </div>
  </div>
</section>
```

### 핵심 스타일 디테일:
- **`.stage`**: `background: var(--surface); border: 1px solid var(--line-strong); border-radius: var(--r);`
  - 상단 타이틀 띠: `::before` 가상 요소로 `"직접 조작해 보세요"` 회색 헤더 자동 삽입.
  - 하단 모니터 바: `.readout` (`background: var(--surface2); font-family: "IBM Plex Mono"; border-top: 1px solid var(--line);`).
- **`.prompt`**: `background: var(--surface2); border-left: 3px solid var(--brand); border-radius: 0 var(--r-sm) var(--r-sm) 0; padding: 16px;`
- **`.copy` 버튼**: 클릭 시 `"복사됨"` 텍스트 변경 + 토스트 알림 팝업.

## 7. 부가 학습 모듈 (실험실, 퀴즈, 경고)

### 1) 여백 실험실 (`.block#lab`)
- 슬라이더 3종(안쪽 여백 `padding`, 바깥 여백 `margin`, 줄 간격 `line-height`)으로 실시간 조작.
- 실시간으로 `.lab-card`의 CSS를 변경하며 `"권장값으로 되돌리기"` 버튼 제공.

### 2) 퀴즈 블록 (`.block#quiz`)
- 1문항당 3~4개 선택지(`.opt`).
- 정답 선택 시 초록 틴트(`.opt.right`), 오답 시 빨간 틴트(`.opt.wrong`)와 정답 해설(`.why`) 노출.
- 하단에 `score` 점수 실시간 집계 (`0 / 5`).

### 3) 자주 빠뜨리는 것 (`.warns`)
- 2열 그리드로 구성.
- 각 경고 상단에 레드 모노 넘버(`.n`: `01`, `02`, `03`, `04`) 표기.

### 4) 헷갈리는 짝 (`.pairs`)
- 2열 그리드로 구성.
- 개념 대비(`체크박스 vs 토글`, `리스트 vs 표` 등)를 한눈에 비교.

## 8. 접근성 & 인터랙션 가이드

1. **포커스 링**:
   ```css
   :focus-visible {
     outline: 2px solid var(--focus);
     outline-offset: 2px;
     border-radius: 3px;
   }
   ```
2. **숫자 고정폭**:
   - 시간, 통계, 카운터, 표 데이터에는 반드시 `font-variant-numeric: tabular-nums` 또는 `.mono`를 적용하여 숫자가 흔들리지 않게 합니다.
3. **애니메이션 최소화 모드**:
   ```css
   @media (prefers-reduced-motion: reduce) {
     * { animation-duration: .01ms !important; transition-duration: .01ms !important; }
   }
   ```
